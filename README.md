# FCA — вайбовый музыкальный плеер для Android

Локальный плеер на Kotlin + Jetpack Compose + Media3. Берёт треки и обложки из памяти телефона,
группирует по альбомам и исполнителям, умеет плейлисты с вайбом и цветом, держит медиа-уведомление
с кнопками, имеет эквалайзер и умеет собирать плейлисты через любой ИИ по JSON.

## Что умеет

- **Библиотека из метаданных.** Название, исполнитель, альбом, год, номер трека и обложка читаются из тегов файла через MediaStore. Новые файлы подхватываются автоматически.
- **Группировка.** Вкладки «Треки», «Альбомы», «Артисты», «Плейлисты». Экран альбома и исполнителя с градиентом в цвет обложки.
- **Плейлисты с вайбом и цветом.** 16 вайбов (Чилл, Энергия, Ночная поездка, Фокус, Вечеринка…), каждый со своим цветом. Цвет можно задать вручную из палитры или слайдером оттенка. Весь интерфейс перекрашивается в цвет играющего плейлиста, а без плейлиста — в доминирующий цвет обложки.
- **Уведомление плеера.** Постоянное медиа-уведомление с обложкой, названием, кнопками пауза / следующий / предыдущий. Работает экран блокировки, гарнитура, Bluetooth, Android Auto.
- **Эквалайзер.** Системные пресеты, ручные полосы, усиление басов, объёмный звук, loudness. Настройки сохраняются.
- **Плеер.** Очередь с перестановкой и удалением, перемешивание, повтор (всё / один), таймер сна, «играть следующим», поиск по всему.
- **ИИ-плейлисты.** Экран «ИИ-плейлисты» копирует промпт со всеми треками. Отдаёшь его ChatGPT / Claude / Gemini, вставляешь полученный JSON — плейлисты создаются с названиями, вайбами, цветами и описаниями.

## Формат JSON для ИИ

Промпт генерируется в приложении (там же есть кнопка «Поделиться»). Ожидаемый ответ:

```json
{
  "playlists": [
    {
      "name": "Ночной неон 🌃",
      "vibe": "NIGHT_DRIVE",
      "color": "#8E24AA",
      "description": "Синтвейв и медленный бит для дороги после полуночи",
      "tracks": [12, 48, 103]
    }
  ]
}
```

- `tracks` — числовые id из промпта. Также принимаются строки `"Исполнитель — Название"` и объекты `{"title": "...", "artist": "..."}`; плеер сопоставит их с библиотекой по названию.
- `vibe` — любое из: `CHILL, ENERGY, FOCUS, NIGHT_DRIVE, PARTY, ROMANCE, MELANCHOLY, RAGE, DREAMY, SUNSET, RETRO, DARK, WORKOUT, SAD, HAPPY, NATURE` (русские названия и близкие слова тоже понимаются).
- `color` — HEX; если не указан, берётся цвет вайба.
- Markdown-ограждения ```` ```json ```` и текст вокруг JSON игнорируются.

## Сборка

Требуется JDK 17 и Android SDK (compileSdk 35). Минимальная версия Android — 8.0 (API 26).

```bash
./gradlew assembleDebug      # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease    # подписан debug-ключом, ставится напрямую
```

В репозитории есть workflow GitHub Actions (`.github/workflows/android.yml`): при каждом пуше собираются
debug- и release-APK и выкладываются в Artifacts запуска.

## Huawei / Honor / Xiaomi: плеер на экране блокировки

В Android нет виджетов экрана блокировки, плеер там рисует система из медиа-уведомления и MediaSession
приложения. Оба уже есть. Если уведомление пропадает или музыка обрывается в фоне, виновато
энергосбережение прошивки. Приложение само покажет подсказку на вкладке «Плейлисты», а вручную:

1. Настройки → Батарея → Запуск приложений → FCA → выключить «Автоматически», включить все три пункта.
2. Настройки → Приложения → FCA → Батарея → «Без ограничений».
3. Настройки → Уведомления → FCA → разрешить показ на экране блокировки.

## Как переименовать приложение

Название задаётся одной строкой `app_name` в `app/src/main/res/values/strings.xml`. Варианты, которые
хорошо ложатся на концепцию: **Vibra**, **Chroma**, **Moodwave**, **Aura**, **Hue**, **Tonal**.

## Структура

```
app/src/main/java/app/fca/player/
├── ai/            AiImport — промпт, разбор JSON, сопоставление с библиотекой
├── data/
│   ├── media/     MediaStoreScanner, LibraryRepository (треки → альбомы → артисты)
│   ├── model/     Track, Album, Artist, Playlist, Vibe, EqSettings
│   ├── playlist/  PlaylistRepository (JSON-файл)
│   └── prefs/     SettingsRepository
├── playback/      PlaybackService (Media3), PlayerConnection, AudioEffects, ArtworkPalette
└── ui/            Compose: тема, навигация, компоненты и экраны
```
